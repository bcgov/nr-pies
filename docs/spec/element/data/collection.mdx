Represents a collection. A collection serves as a common construct for describing resource data elements that group
other data elements together.

## Scope

This data type is intended to only be transmitted as a part of any resource data element focusing on grouping or
aggregating other data elements together. A collection is defined as an independent, common composable data type and may
be used in other message contexts.

## Structure

This structure contains no properties at this time and is functionally equivalent to an empty object.

## Implementation Guidance

The Collection data type is an empty object and does not define any properties. Systems parsing collections should
ignore any unexpected properties.

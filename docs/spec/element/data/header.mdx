Represents the standard message tracking envelope, incorporating specific asset attributes for system and record
identification. All defined attributes are needed for asset identification and attribution and are present for all PIES
message data types.

## Scope

This data type is intended to define all expected attributes that a message datatype must contain at minimum. This
data structure is not intended for standalone use.

## Structure

:::info
A **Header** extends the following data types and inherits all of their declared attributes:

- **[Asset](/docs/spec/element/data/asset)**

The table below lists only the direct properties declared by Header.
:::

| Name           | Cardinality | Type                                   | Description & Constraints                                                                                                                              |
| -------------- | ----------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| _(Asset)_      | 1..1        | [Asset](/docs/spec/element/data/asset) | Standard message asset attributes present for all PIES message data types.                                                                             |
| transaction_id | 1..1        | `string`                               | A unique UUIDv7 assigned for this specific message.                                                                                                    |
| version        | 1..1        | `string`                               | The PIES specification version this message complies to. Value shall be a valid semantic version formatted string.                                     |
| kind           | 1..1        | [Code](./code)                         | A valid [Message Kind](/docs/spec/code_system/message_kind) code which identifies the specific kind of PIES message data type this message represents. |

## Implementation Guidance

All header and asset attributes are mandatory. A valid PIES message datagram must define all of the header and asset
attributes.
